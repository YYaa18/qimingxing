# Triage 标签

技能使用五个规范的 triage 角色。本文件把这些角色映射到本仓库 issue 跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该 issue |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完全明确，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当技能提到某个角色时（例如「应用 AFK-ready triage 标签」），使用表中对应的标签字符串。

修改「本仓库跟踪器中的标签」列即可匹配你实际使用的词汇。
